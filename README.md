# Trackside demo

This is the **built demo** of Trackside, a derby race manager (a Derby Magic replacement).
Only the compiled web app is published here; the source code is in a private repository.

Try it: https://jafitzwater.github.io/trackside-demo/

- Use the built-in **timer simulator** (default) and **Load sample roster** on the Roster screen.
- All data stays **in your browser** on your device. Nothing is sent to a server.
  Clearing site data or using a private/Incognito window erases it.
- The real Derby Magic USB timer needs Chrome or Edge on a computer; phones can only use the simulator.
